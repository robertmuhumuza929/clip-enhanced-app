# Clip APK readiness checklist

- [ ] Extract the project
- [ ] Run `npm install`
- [ ] Run `npm run doctor`
- [ ] Install EAS CLI
- [ ] Run `eas login`
- [ ] Run `npm run build:apk`
- [ ] Install the generated APK
- [ ] Import a short video
- [ ] Test trim
- [ ] Test filters
- [ ] Test text
- [ ] Test volume
- [ ] Test export
- [ ] Confirm the exported video appears in the gallery
